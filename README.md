# TypeScript Assignment

## Assignment Overview

This assignment covers fundamental and advanced TypeScript concepts, including functions, type safety, generics, interfaces, tuples, asynchronous programming, and Object-Oriented Programming (OOP).

### Topics Covered in this Assignment

- Union types and type narrowing
- Readonly tuples
- Interfaces and array filtering
- Generics with keyof constraints
- OOP concepts: classes, inheritance, encapsulation, and access modifiers
- Promises and asynchronous programming
